# 🎓 Study Vision

Study Vision is an AI-powered chatbot built using **Python, Gradio, and Google's Gemini API**.

It provides a simple chat interface where people can ask questions and get AI-generated explanations.

---

## ✨ Features

- 💬 Interactive chatbot interface using Gradio
- 🤖 Powered by Google Gemini AI
- 📚 Useful for educational and study-related questions
- ⚡ AI-generated responses
- 🎨 Simple and clean user interface

---

## 🛠️ Technologies Used

- **Python**
- **Gradio** – For creating the chatbot web interface
- **Google Gemini API** – For generating AI responses
- **Google GenAI Python SDK** – To communicate with Gemini
- **python-dotenv** – To load the API key securely from `.env`
